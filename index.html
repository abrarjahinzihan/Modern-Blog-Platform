    Core Competencies & Requirements

    This project satisfies and showcases all 5 key requirements from the internship specification:

    1 CSS Grid Layout Architecture

    Built with responsive grid systems (grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8) alongside featured asymmetric editorial spans (lg:col-span-12 and md:col-span-2) for visual dynamism.

    2 Web Typography & Editorial Hierarchy

    Sophisticated font pairing utilizing Newsreader and Instrument Serif for editorial authority, Plus Jakarta Sans for modern UI navigation, and JetBrains Mono for metadata and code. Includes drop caps, golden ratios, and reader font-scaling.

    3 Card Layouts with Category Badges & Reading Times

    Each article card contains color-coded category badges, accurate reading time calculations, hover zoom animations, tag chips, and author metadata with avatars.

    4 Responsive Layout Across Mobile, Tablet & Desktop

    Fluid breakpoints, horizontal tag scrolling, collapsible drawer readers, responsive banner grids, and touch-friendly targets ensure seamless reading on all devices.

    5 UI Hierarchy, Contrast & Reader Immersion

    Clear typographic contrast (Display Serif > H1 > H2 > Lead Prose > Meta), live reading progress tracking, Night/Day mode persistence, and interactive bookmarking.
